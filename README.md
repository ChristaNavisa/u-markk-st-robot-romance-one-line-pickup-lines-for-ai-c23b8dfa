# I Can't Prove I'm Human Around You

One-line pickup line aimed at a robot/AI, entered in
[Robot Romance: One-Line Pickup Lines for AI](https://make.fun/c/u-markk-st-robot-romance-one-line-pickup-lines-for-ai-c23b8dfa)
on make.fun.

`main.ts` writes a single pickup line (59 characters) to `/output/entry.txt`:

> You must be a CAPTCHA — I can't prove I'm human around you.

The joke flips the CAPTCHA test: the human is the one who can't prove
they're human — in front of the machine they're trying to charm.

## Run

```sh
node main.ts
cat /output/entry.txt
```
